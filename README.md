# Консольное приложение для учёта книжного фонда библиотеки

Делали: Соколов А., Суворов А.
Группа: 9ИС-345
Стиль кода: Google C++ Style Guide
## Цель работы

Закрепить навыки объектно-ориентированного программирования, работы со стандартной библиотекой STL, файлового ввода-вывода, проектирования модульных приложений и обработки пользовательского ввода в среде C++.

## Постановка задачи

- Реализовать полноценное CRUD-приложение для управления каталогом книг.
- Обеспечить поиск, фильтрацию и сортировку записей.
- Рассчитывать аналитические показатели фонда библиотеки.
- Реализовать автозагрузку и ручное сохранение данных в текстовый файл.
- Создать удобное консольное меню с обработкой ошибок ввода.

## Технические требования

Язык программирования - C++17
Компилятор - GCC / MSVC (любой, поддерживающий C++17)
Хранение данных в памяти - `std::vector`
Формат файла данных - `.txt` с разделителем `,`
Обработка ошибок ввода - Без аварийного завершения программы
Стиль кода - Google C++ Style Guide

## Инструкция по установке и запуску

### Требования

- Компилятор с поддержкой C++17 (GCC ≥ 7, MSVC ≥ 2017, Clang ≥ 5)
- CMake ≥ 3.16 (опционально, если собирать через CMake)

### Вариант 1: Сборка через CMake (рекомендуется)

```bash
git clone https://github.com/ShadowAAHW/library
cd LibraryApp
mkdir build && cd build
cmake ..
cmake --build .
```

**Запуск:**
- Windows: `LibraryApp.exe` (в папке `build`)
- Linux / macOS: `./LibraryApp`

### Вариант 2: Сборка через g++ вручную

```bash
git clone https://github.com/ShadowAAHW/library
cd LibraryApp
g++ -std=c++17 src/*.cpp -o LibraryApp
./LibraryApp
```

### Вариант 3: Visual Studio

1. Создать пустой C++ проект.
2. Добавить все файлы из `src/`.
3. В свойствах проекта установить **C++ Language Standard = C++17**.
4. В свойствах компилятора добавить флаг `/utf-8` (для корректной работы с кириллицей в исходниках).
5. Собрать и запустить.

> При первом запуске программа автоматически создаст папку `data/` и пустой файл `catalog.txt`, если их нет.
